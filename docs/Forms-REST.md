# Forms REST API Documentation

Endpoint: `/wp-json/wp-ai-os/v1/forms`

- `GET /wp-json/wp-ai-os/v1/forms` - List all forms
- `POST /wp-json/wp-ai-os/v1/forms` - Create a new form
- `GET /wp-json/wp-ai-os/v1/forms/{id}` - Get form details
- `DELETE /wp-json/wp-ai-os/v1/forms/{id}` - Delete a form
- `GET /wp-json/wp-ai-os/v1/forms/providers` - Get discovered form provider plugins
